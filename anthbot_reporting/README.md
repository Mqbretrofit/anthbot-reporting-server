# ANTHBOT Reporting Server

This reporting backend is intended for the project maintainer/developer infrastructure, not for ordinary ANTHBOT Map Home Assistant users.

The server currently lives in this repository only as a transitional deployment source. It should be migrated to a dedicated repository so the public ANTHBOT Map repository contains only the Home Assistant integration/card and the client-side opt-in reporting code.
