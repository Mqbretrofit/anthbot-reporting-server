# Dashboard error statistics

This branch is reserved for the requested ANTHBOT statistics dashboard extension.

## Requested dashboard additions

- Robot model × error/stuck-event statistics.
- Error/event distribution that can be measured from reported diagnostics.
- Keep the existing installation, activity, model, version and diagnostics statistics unchanged.
- Surface the existing error statistics dashboard from the main statistics UI.

The implementation must reuse existing reporting data and must not change the existing presence heartbeat or opt-in detailed Reports behavior.
