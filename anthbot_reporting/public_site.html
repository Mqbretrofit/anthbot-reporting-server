What ANTHBOT Map actually does

Built around the real mower workflow, not a generic dashboard.

The site now mirrors the integration itself: the same dark Home Assistant card language, the same green active accent, the same map overlays and the same major panels found in the bundled anthbot-map-card.

Live map without Recorder overloadHigh-frequency path and pose updates use a dedicated WebSocket transport with full snapshots, incremental deltas, sequence handling and automatic resync.
Native ANTHBOT schedule as source of truthThe Schedule panel mirrors app rules and can create, edit and delete supported native weekly schedules, including zones, cutting height and optional weather logic.
Map, zones, No-Go and historyDisplays lawn boundary, mapped zones, No-Go geometry, mower position, live path, mowing coverage and previous task detail where the model exposes it.

Current integration feature set

This list is based on the current public Anthbot Map repository, not placeholder marketing copy.

⌖
Map

Map, path & coverage

Boundary, zones, No-Go areas, mower position, live mowing path, coverage, optional aerial/drone background, fullscreen, zoom, pan and rotation.

▶
Control

Model-aware mower commands

Full lawn, zones, outer edge and dock surroundings where supported, plus pause, resume, stop and return-to-dock with separated model routing.

◷
Schedule

Native schedules & overrides

ANTHBOT app schedules mirrored to Home Assistant, write-back editing, next-mow sensor, timed mow/park overrides and native mower events.

☁
Automation

Weather-aware scheduling

Optional weather start guard, forecast checks, rain holds and bounded catch-up windows for supported scheduling workflows.

▰
Energy

Battery Saver

Battery Saver profiles, charge thresholds, shared or separate RTK power behavior and restart-persistent state, plus the supported Shutdown Guard flow.

↺
History

Mowing history

Previous mowing tasks can expose date, duration, area, progress, start reason, zones and historical map/path data where available.

⚙
Diagnostics

Diagnostics & developer tools

Optional anonymous statistics, automatic diagnostics, task-event diagnostics and separately permissioned read-only Developer Agent tools.

◎
Calibration

Precise visual calibration

Separate base-map, mower, mowing-path and decoded-boundary calibration for matching real garden imagery and mower geometry.

文
UI

23 interface languages

The map card provides selectable interface languages while retaining Home Assistant-native entities and automation access.

Model-specific support

Anthbot Map does not force every mower through one generic protocol path.

Genie

Directly hardware-tested. Genie-specific command, map/path and diagnostic behavior remains isolated from M-series routing.

M9 Pro / M-series

M9 Pro is directly hardware-tested with map, path, zones, history and current live-stream architecture. M9 and M5 share the M-series implementation, with model-specific handling where known.

N8

Dedicated N8 implementation with separate routing and regression coverage; direct current hardware validation remains pending in the public project documentation.

Pion / MGC

Dedicated Pion/MGC family handling for identifiers such as MGC500, MGC750 and MGC1000, including confirmed status normalization and native schedule behavior while unverified writes stay disabled.
